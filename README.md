# Task 1: Business Sales Performance Analytics

## Overview
This project provides a comprehensive analysis of sales performance using the Superstore dataset. It evaluates total revenue, profit margins, top-performing product categories, key product drivers, and regional trends.

## Key Insights
- **Total Revenue:** $2,297,200.86 across 5,009 unique orders.
- **Total Profit:** $286,397.02.
- **Top Product Category:** **Technology** generated the highest sales ($836,154.03) and highest profit ($145,454.95), followed by **Furniture** ($741,999.80) and **Office Supplies** ($719,047.03).
- **Top Generating Product:** *Canon imageCLASS 2200 Advanced Copier* brought in $61,599.82 in total revenue.
- **Top Regional Market:** The **West** region leads overall sales ($725,457.82) and profit ($108,418.45), while the **South** represents the smallest market share ($391,721.91).

## Tools Used
- **Python 3.13**
- **Pandas** for data processing and aggregation
- **Matplotlib & Seaborn** for data visualization
